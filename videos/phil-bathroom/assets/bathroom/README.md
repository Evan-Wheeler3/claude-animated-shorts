# Hold Up | Phil bathroom reveal

An editable 3D recreation of the approved bathroom reveal, staged for the early-PC-game look. The set uses repeating olive tile, aged porcelain, a warm wall sconce, and a dark window. The two cast models use realistic adult proportions and textured faces. The brief hold and eye movement carry the punchline.

**For Claude.** Start with [CLAUDE-PROMPT.md](CLAUDE-PROMPT.md). Use the full shot GLB and the supplied Three.js loader. If transforming the shot for the episode, review the opening framing so Phil enters the shot during the pan.

**For Blender.** Open `Bathroom_Reveal.blend`, set frame 139, and render from the active camera. All used image textures are packed. Collections group the room, cast, held props, and camera/lighting. Blender frames run 1–151 at 30 fps.

**For delivery review.** The approved concept still and both renderer proofs are packaged. The Three.js motion proof is a silent blocking preview. The editor can add the single audio cue at the cut described in the Claude prompt. The concept proportions and room palette are carried into the render. The adapted facial likenesses, foam surface, and light falloff are approximate.
