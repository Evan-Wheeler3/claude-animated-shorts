# Isolated renderer adapter

The approved story branch deliberately contains no renderer, package.json or `src/pipeline`. Test previews were rendered in a **separate detached worktree** at `a090f70227f92483ff856856000d6ceda6828e80` (our previous Codex branch, based on Niagara `93f2dbe`). Never reset or modify Claude's active branch. With that isolated runtime checked out and dependencies installed, copy `Preview.tsx`, `cast.ts`, `materials.ts`, `index.tsx` into `src/videos/submarine-toilet/`, and copy `submarine-stills.mjs` into `scripts/`. Supply this story's four `assets/*.js` files at the runtime's `videos/submarine-toilet/assets/` (in the local test they were symlinks to this branch). The opt-in `subcap` renderer change is already at `a090f70`; for an isolated runtime on `93f2dbe`, `opt-in-watch-cap.patch` is supplied, but applying it to the active Claude branch is prohibited. Render with `CHROME=/usr/bin/chromium node scripts/submarine-stills.mjs`; Chromium required elevated process permission in this environment. Select scenes with `ONLY=ocean,flood`; use `OFFSET=10 TAG=early-` to sample a different frame and retain both outputs. The script writes to the isolated runtime's `videos/submarine-toilet/previews/`.

Local dependency versions: Three.js 0.169.0, Remotion 4.0.544 and React 18.3.1 from the runtime lockfile. This overlay is a QA harness, not an installed production integration, and no claim is made that it will remain compatible with Claude's evolving runtime.
