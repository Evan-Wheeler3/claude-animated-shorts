# Kenney Sedan

Original Sedan from [Kenney Car Kit](https://kenney.nl/assets/car-kit), under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The original GLB and palette are vendored unchanged from this [source snapshot](https://github.com/shorepine/kenney/tree/3694c6879e487c108f55677be7dd2ca75b07cc3b/3d/car).

Load `sedan.glb` with Three.js `GLTFLoader`. Serve `Textures/colormap.png` relative to the GLB. The asset is Y-up and faces +Z. The wheels sit at ground level. The body is about 2.55 units long, 1.5 wide, and 1.3 tall including wheels. The four wheel nodes have their own pivots.

This model has four wheel meshes and a single opaque body mesh. The windows are painted on that body. To use it in a shot where the driver must be visible, adapt the window faces and fit a cabin and driver, or use the existing cabin car for those shots. The GLB is supplied as a sourced option for Claude.
